# Setup Instructions (Local)

1. Clone the repo:
   - `git clone <your-repo-url>`
2. Backend:
   - `cd server`
   - `npm install`
   - Copy `.env.example` to `.env` and set `MONGO_URI` if available.
   - `node server.js`
3. Frontend:
   - `cd client`
   - `npm install`
   - `npm run dev`
